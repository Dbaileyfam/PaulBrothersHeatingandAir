# Paul Brothers Heating & Air

Professional local HVAC website for Paul Brothers Heating & Air — Midvale, Utah and Salt Lake County.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

This project is set up for deployment to [GitHub](https://github.com/Dbaileyfam/PaulBrothersHeatingandAir.git).

After pushing to GitHub, connect the repo to your hosting provider (Vercel, Netlify, GitHub Pages, etc.) and set the build command to `npm run build` with output directory `dist`.

## Business info

Edit `src/content/site.ts` to update phone numbers, service areas, copy, and trust signals across the site.

LocalBusiness / HVACBusiness structured data lives in `index.html`.
