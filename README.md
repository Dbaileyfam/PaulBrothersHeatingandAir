# Paul Brothers Heating & Air

Professional local HVAC website for Paul Brothers Heating & Air — Midvale, Utah and Salt Lake County.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Live preview (GitHub Pages)

**https://dbaileyfam.github.io/PaulBrothersHeatingandAir/**

This is separate from the existing site at [paulbrothersutah.com](https://paulbrothersutah.com). When you're ready to switch domains later, add a `public/CNAME` and update DNS.

## Business info

Edit `src/content/site.ts` to update phone numbers, service areas, copy, and trust signals across the site.

LocalBusiness / HVACBusiness structured data lives in `index.html`.
